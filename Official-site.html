WaveBreaker Recorder

About: Wavebreaker is an audio recorder software with rnnoise background noise cancellation. The noise cancellation works best with a clean mic. Wavebreaker also has a live record option for using in presentations so theres less echo and feedback. With the live record you could also use a virtual audio out that channels the audio pipeline towards other software see WASAPI Docs and PipeWire Docs for more info.
